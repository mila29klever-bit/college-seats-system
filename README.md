# Автоматизированная система учёта рабочих мест студентов

## Описание
Веб-приложение для автоматизации учёта распределения компьютеров между студентами учебных групп колледжа.

## Функциональность
- Просмотр списка студентов группы с закреплёнными рабочими местами
- Поиск студентов по номеру компьютера
- Добавление, редактирование и удаление групп и студентов
- Экспорт данных в Excel (одна группа или все группы)

## Технологический стек
- **Backend:** PHP 7.4+
- **База данных:** MySQL / MariaDB
- **Frontend:** HTML5, CSS3
- **Сервер:** XAMPP (Apache 2.4)

## Установка

1. Скопируйте файлы проекта в папку `htdocs` XAMPP
2. Скопируйте `db.example.php` в `db.php` и настройте подключение
3. Откройте `http://localhost/seats/install.php` для создания БД
4. Перейдите на `http://localhost/seats/index.php`

## Структура базы данных
- `groups` — учебные группы
- `computers` — рабочие места
- `students` — студенты (связаны с группой и компьютером)
